Make a gauntlet

String maps together into a run for friends, a club or a class. In the game's setup menu, set up a map with a fixed seed and press Get Link, or use Challenge a friend after a game. Paste one link per stage here, write what each stage should teach, and save.

Saving gives you a link that opens the gauntlet in the game's Tutorial list. Each stage opens once the one before it is won, or won within its target if you give it one: your own score from a Challenge a friend link, or the best bot's on the board.

Open in the game

Desktop players: put the .json file in the game's gauntlets folder.
